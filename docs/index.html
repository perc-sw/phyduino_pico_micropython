Introduction to Electronics - MicroPython library

A one-file MicroPython library for the Phyduino Pico. It runs on the standard Raspberry Pi Pico firmware and adds what that firmware doesn't know about this board: the pin names printed on the board ("D7", "A3"), the on-board LED, A3–A5 on the on-board MAX11635 ADC, the USB-C supply voltage and USB-PD power.

MicroPython RP2040 VS Code · PyCharm Windows · Linux · macOS v0.1.0-rc.1

Set up

  1. 1 Download the latest Raspberry Pi Pico (RP2040) MicroPython UF2 from micropython.org.
  2. 2 Slide SW1 to GND (BOOTSEL) and press reset (SW2). Copy the UF2 to the RPI-RP2 drive that appears, then slide SW1 back to 3.3 V and press reset.
  3. 3 Download phyduino.py from the repository and put it in your project folder, next to your own main.py.
  4. 4

    VS Code: install the MicroPico extension, right-click phyduino.py and choose Upload file to Pico, then open main.py and click Run.

    PyCharm: install the MicroPython Tools plugin, then upload phyduino.py and run main.py.

    Terminal: mpremote cp phyduino.py : then mpremote run main.py.

     
import phyduino as pd

pd.led.on()
print(pd.analog_volts("A3"))             # 0-2.048 V, on-board MAX11635
button = pd.pin("D2", "in", pull="up")

What the library provides

Pins PINS, pin(), gpio(): the board's pin names as strings API
On-board LED led.on(), off(), toggle(), value() · example: blink API
Analogue inputs A0–A5 as codes, millivolts or volts, averaging, differential · examples: analog_read, analog_millivolts, analog_averaging, analog_differential API
Power and temperature vbus_volts(), cpu_temperature(), USB-PD profiles and contract · examples: vbus_monitor, usb_pd_power API
Header buses i2c(), spi(), uart() on the header pins · examples: i2c_scan, uart_loopback API
External ADC The MAX11635 behind A3–A5, by channel: scans and raw differential readings API
